<h2>Problem Statement</h2>
<p>Many individuals face difficulty in getting immediate medical guidance, especially in identifying the right treatment approach, nearby hospitals, and expected costs. There is often a lack of accessible, quick, and reliable preliminary healthcare information.
</p>
 <hr>
 <h2>Overview</h2>
 <p>This project is a Healthcare AI System built using CrewAI that provides basic medical assistance through multiple intelligent agents. It helps users understand diseases, suggests treatment plans, recommends nearby hospitals, and estimates treatment costs. The system integrates AI models and APIs to deliver quick and structured healthcare information. It is designed to simplify medical guidance for general users in an accessible and efficient way.</p>
 


<hr>
<h2>Objective</h2>
<ul>
<li>To explain diseases in a simple and understandable manner</li>

<li>To generate step-by-step treatment plans</li>

<li>To recommend hospitals based on user queries</li>

<li>To estimate treatment costs in Indian Rupees</li>

<li>To provide a complete healthcare assistance system using AI agents</li>
</ul>

<h2>Key Features</h2>
<ul>

  <li>Step-by-step treatment plan generation</li>
  <li>Hospital recommendation with location links</li>
